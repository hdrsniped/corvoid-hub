# Changelog

## 1.1.0 — 2026-11-20

- Quick log works out of the box: the app writes log lines and ticks tasks itself (no scripts needed)
- Needle add-on (optional, offline): plain-language commands in Ctrl+K, with a preview you confirm before anything is written
- First-run setup (with an AI or manually), connects global rules to each harness with backups
- Backups: one-file export, daily or weekly automatic backups, restore into a new folder
- Antigravity icon read from the installed app; long project titles no longer push the status badge

## 1.0.0 — 2026-11-20

First public release.

- Projects, Activity, Mind graph, Hub, Skills, Apps and Guide screens
- Skills: move between the hub, Claude Code and Antigravity; remove to a backup
- Transfer a project to another harness with one prompt
- Locks (read-only, no-ai), Ctrl+K search, Ctrl+L quick log
- Paths come from `corvoid-hub.json` instead of being built in
